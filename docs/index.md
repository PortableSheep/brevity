# Brevity Node

TypeScript microframework inspired by your PHP Brevity project.

## Why this exists

- Keep the same mental model as Brevity PHP
- Stay slim and readable
- Make architecture easy to learn and extend

## Features

- Router with typed route params
- Middleware pipeline
- Container + service providers
- Request validation
- Cache manager
- Minimal viewer
